Built-in user manual

Help / How to Use the Recording Module

This guide explains the main customer actions in simple language. The app still keeps technical logs hidden and shows user-facing issues through the Review & Error Center.

1. Record income or expense: Open Transactions, enter the date, accounting month, type, amount, rate, method, description, and save.

2. Attach receipt/proof: Use Optional Receipt / Proof Picture when a transaction needs evidence. Cloud users can store files in Supabase Storage; local-only users save metadata only.

3. Check the ledger: Open General Ledger to see Bank, Cash, AR, AP, income, expense, asset, liability, and equity movements with debit, credit, balance b/d, and balance c/d.

4. Read warnings: Open Review & Error Center to see missing receipts, possible duplicates, negative balances, pending saves, and cloud-sync issues.

5. Save and backup: Use Save to Cloud for Supabase and Export JSON for emergency backup. Auto-save runs 30 seconds after record changes when cloud is active.

6. Monthly closing: Use the Monthly Closing Checklist before moving a month into the next Organising Module.

7. Security: The app warns before auto logout, attempts a safe save if needed, then logs out after inactivity without deleting records.
